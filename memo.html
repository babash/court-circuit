Court-circuit : le mémo

Ton robot colorie les cases où il passe ; une case adverse sur laquelle tu passes devient la tienne. Après 30 s, le plus de cases gagne.

Prénom :Classe :
En ligne : babash.github.io/Babash-NSI-SNT/snt/fichiers/court-circuit/
À vos smartphones !Jouer

Les actions (une à la fois)

nord() sud()
est() ouest()		avance d’une case dans cette direction et la colorie ; le nord est en haut de ton écran
eclair()éclair dans les 4 directions, sur 3 cases : l’adversaire touché est figé 2 s et les cases autour de lui deviennent les tiennes
poserCaisse()pose une caisse sur ta case (3 par match) : quand tu en sors, plus personne n’y passe
attendre()ne fait rien

Les capteurs (des questions)

obstacleNord()Vrai si la case au nord est un mur, une caisse, le bord ou l’autre robot ; aussi obstacleSud(), obstacleEst(), obstacleOuest()
couleurNord()"vide", "moi", "adversaire" ou "mur" ; aussi couleurSud()…
cible()Vrai si un éclair toucherait l’adversaire ; dans une seule direction : cibleNord(), cibleEst()…
distance() caisses()les cases jusqu’à l’adversaire ; les caisses qu’il te reste

L’essentiel

Boucle bornée : répéter un nombre de fois fixé.
for i in range(4):
    nord()
Boucle non bornée : répéter tant qu’une condition est vraie.
while True:
    while not obstacleNord():
        nord()
    est()
Fonction : donner un nom à des lignes, puis l’appeler.
def zigzag():
    nord()
    est()
zigzag()        # fait nord(), puis est()
Attention : une ligne qui commence par for, while, if, elif, else ou def finit par « : », et les lignes de son bloc sont décalées de 4 espaces.

Vitesse : chaque ligne recopiée ralentit ton robot. Une boucle ou une fonction évite de recopier.
